# Plugixa Exam — free version

Git mirror of the **free version** of [Plugixa Exam](https://wordpress.org/plugins/plugixa-exam/)
as published on WordPress.org.

- SVN repository: <https://plugins.svn.wordpress.org/plugixa-exam/>
- Git tags match the SVN `tags/<version>` directories (current release: **1.4.0**)
- Development takes place in the internal Plugixa repository; this repository tracks
  what WordPress.org distributes. Please report issues on the
  [plugin support forum](https://wordpress.org/support/plugin/plugixa-exam/).

The premium version of Plugixa Exam is distributed separately and is **not** contained
in this repository.
