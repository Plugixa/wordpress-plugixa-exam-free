## What it is

🎓 A complete exam system for WordPress, free and not feature-locked:

- **Question bank** — seven question types, explanations, rubrics, pictures; import from CSV, Aiken, GIFT, Moodle XML and QTI
- **Exam builder** — sections that are a fixed list or a pool drawn by subject, tag, difficulty and type; questions and options shuffled
- **Runner** — server-side timing, autosave, pause and resume, and it works without JavaScript
- **Marking** — automatic on submission, with a queue for essays and anything you mark by hand
- **Certificates** — awarded on a pass, rendered as a real PDF, verifiable through a QR code
- **Learners** — a dashboard, an exam catalogue, blocks and shortcodes such as `[plugixa_exam_catalogue]`
- **Admin** — a fast Material UI application, five seeded roles, a schedule calendar, GDPR export and erasure

A full tour with every feature is on the [documentation](https://www.plugixa.com/documentation/plugixa-exam?utm_source=github.com&utm_medium=repo_readme&utm_campaign=plugixa-exam&utm_content=docs) — and on the [WordPress.org plugin page](https://wordpress.org/plugins/plugixa-exam/).

## Who is it for?

Schools and universities sitting timed papers. Training centres and certification bodies issuing numbered certificates with a public verification page. Companies and HR teams running induction tests where candidates do not have an account on the site yet. Any course site — the exam pages render inside the active theme.

## Get it

The free plugin itself is hosted on WordPress.org — install it from your dashboard (**Plugins → Add New → search "Plugixa Exam"**) or fetch it directly:

```
Latest release:  https://downloads.wordpress.org/plugin/plugixa-exam.latest-stable.zip
Install by ZIP:  Plugins → Add New → Upload Plugin → choose the ZIP → Activate
```
